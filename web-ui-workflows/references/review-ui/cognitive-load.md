# 认知负荷检查

按本次读者任务观察信息如何被识别、比较和操作。可见选项数量不等于必须记忆的信息量；不以固定项数或清单命中数判定过载。

| 检查 | 观察对象 |
| --- | --- |
| 主任务 | 竞争元素是否干扰读者找到并完成主要动作 |
| 分组 | 相关项是否归拢，组名能否帮助定位 |
| 视觉层级 | 重要信息是否容易识别，次要信息是否抢占注意 |
| 决策顺序 | 页面是否提供做当前决定所需的信息 |
| 选择与比较 | 选项是否可扫描和区分，必要比较是否被折叠或跳页打断 |
| 记忆负担 | 跨页后是否仍能取得需要比较的身份、条件和值 |
| 渐进披露 | 次要细节能否按需查看，常用操作是否仍易发现 |

报告具体受阻任务、对象、实际操作与影响；数量可以作为读数，但不自动成为缺陷。改法依据本次有效设计与产品约束，保留完成任务所需的信息与选择。
