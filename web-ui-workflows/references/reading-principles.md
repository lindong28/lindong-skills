# 通用阅读原则

本档拥有界面内容的通用可理解性，适用于明确的内容/UX 审核、场景声明的阅读要求，以及改动引入的意义回归检查。应用范围由 [UI 规则归属](ui-rule-ownership.md) 确定；引用本档不自动启动 test-ux、多 persona 或整套契约流程。

通道无关的自解释、结论范围与数值精度原则由 [human-facing-message-principles](portable-runtime.md#视觉与阅读) 拥有；本档只补界面上的观察对象。具体业务含义由产品确定，风格模板只规定呈现。

| 观察对象 | 读者应能完成的判断 |
| --- | --- |
| 当前值、历史值、操作结果 | 分清各自的对象身份、适用时点与来源；历史值不能被呈现成当前状态。需要何种时间精度取决于判断用途，不要求每个值重复时间戳 |
| 未知、不适用与零 | 分清尚无读数、不适用于该对象与真实为零；文案和显示形式可由产品/风格决定，数据状态不可凭外观猜定 |
| 数字、单位与范围 | 理解数量在计算什么、单位与统计范围；主视图提供作判断所需的精度和上下文 |
| 相邻区域与筛选 | 理解哪个结果属于哪个对象/范围，哪些控件影响它；共享视觉不意味着共享筛选语义 |
| 主次与重复 | 找到任务所需答案和动作；共同说明不挤占每条的有效信息；内部术语不迫使用户猜测 |

观察使用真实内容及所声明的状态。明确的单位/文案/状态映射可转为项目断言；业务含义是否正确依产品事实核对，不能靠关键词识别自然语言。布局关联的测量方法归 [web-ui-observation](web-ui-observation.md)。

报告说明读者任务、读到了什么、答案的位置与取得它所需操作；无法观察的项保留未核实。有限内容可通读，长列表按不同内容/状态取样并注明边界。重复文本用 page-repetition 作辅助时核对目标页面身份和统计范围，计数不能替代意义判断。

仅应用风格时，检查既有意义是否被这次改动破坏：例如原本可见的时间被裁掉，属于本次回归；产品从未提供时间或状态定义，则单列基线阅读/产品问题。修复后复验同一对象及受影响的其他实例，避免用另一处已通过代替本处。
