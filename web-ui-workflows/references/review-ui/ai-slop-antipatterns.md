# 视觉套用检查

检查视觉选择是否服务读者任务、符合本次有效设计。颜色、字体、卡片或动效的存在本身不说明质量，也不能证明制作来源。已选风格和产品品牌是判断依据，不因常见或像某种工具产物而替换。

| 观察方向 | 可报告的问题与证据 |
| --- | --- |
| 配色与主题 | 强调色掩盖真实状态、文本对比不足或偏离有效规则；指出实际元素及影响 |
| 容器与布局 | 重复或嵌套容器割裂相关信息、挤压比较空间或拉远主要操作 |
| 排版 | 标题和值的层级混淆、长内容不可读、需要比较的数字无法对齐 |
| 装饰与图表 | 装饰抢占主任务空间，或图形让读者误以为存在未提供的数据 |
| 动效与交互 | 动效导致已观察的卡顿、操作状态不明或不必要的中断 |
| 响应式 | 重排后关键内容或操作不可达，相关标签和值失去关联 |

先取得实际页面证据，再按适用规则和任务影响写 finding。纯白或纯黑背景、系统字体、等宽字体、均匀网格等均不能单独构成负面结论；无法核实影响时说明未核实，不编造缺陷。
